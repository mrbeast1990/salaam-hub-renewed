# المرحلة السابعة: التقارير ولوحة التحكم ومركز التدقيق

بناء طبقة التقارير والرقابة التي تعتمد حصريًا على البيانات والحركات الفعلية، مع مركز تدقيق احترافي لضمان سلامة البيانات.

## 1. لوحة التحكم (Dashboard)
- إعادة بناء `src/routes/_authenticated/index.tsx` لتعرض إحصائيات موسعة (مبيعات اليوم/أمس/الشهر، المشتريات، المصروفات، الخزينة، المديونيات، قيمة المخزون).
- الاعتماد حصرياً على الـ Views والحركات (Ledgers).
- عرض أحدث الحركات وتنبيهات المخزون المنخفض.

## 2. نظام التقارير
- **تقارير المبيعات والمشتريات**: فلاتر متقدمة (تاريخ، طرف، صنف، حالة)، تفصيل نقدي/آجل/مرتجع.
- **تقرير الأرباح**: حساب الأرباح بناءً على تكلفة الصنف وقت البيع (`sale_items.unit_cost`).
- **تقارير المخزون**: الرصيد اللحظي من `v_product_stock` وقيمة المخزون الإجمالية.
- **تقارير العملاء والموردين**: إجمالي المديونيات وكشوف حسابات تفصيلية.
- **تقارير الخزينة**: تدفقات نقدية وصافي الحركة.

## 3. مركز التدقيق (Audit Center)
- صفحة `/audit` (للقراءة فقط):
    - فحص تناسق البيانات بين المستندات والحركات (Ledger/Inventory/Treasury).
    - كشف الحركات اليتيمة أو مكررات الـ `idempotency_key`.
    - تقييم صحة النظام (Health Score) لكل وحدة.

## 4. الطباعة والتصدير
- توفير نسخ RTL للطباعة لكل تقرير.
- دعم تصدير البيانات الأساسية.

## التقنيات المستخدمة
- **TanStack Start**: Server Functions للعمليات المعقدة.
- **Supabase**: Views و RPCs للعمليات المالية الذرية.
- **Tailwind CSS**: تصميم Apple-like بسيط ومتجاوب.

## الملفات الجديدة والمعدلة
- `src/lib/reports/*`: دوال جلب البيانات والتحليل.
- `src/components/reports/*`: مكونات الواجهة للتقارير.
- `src/routes/_authenticated/audit.tsx`: مركز التدقيق.
- `src/routes/_authenticated/reports/*`: مسارات التقارير التفصيلية.
- `src/routes/_authenticated/index.tsx`: تحديث لوحة التحكم.
